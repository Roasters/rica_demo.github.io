Salience Is Not Grounding

Testing Relational Instruction Control in Audio-Language Models

Listen to two worlds with the same sound identities but reversed relational roles. Then inspect whether changing the instruction reverses the model's preference for a fixed caption.

Five matched pairs per relation, selected using signal QC and sound-class diversity—not model scores. These are illustrative examples, not benchmark averages. Listener validation remains pending. Keep playback volume constant. Audio is not normalized for this page.

How to read the scores

m+ and m−: positive means that the correct world receives the higher likelihood for the selected caption under that instruction. Both must be strictly positive for correct crossover (C = 1). These are comparisons across worlds, not a choice between captions in one recording.

G = m+ + m−: directional instruction sensitivity. A positive G does not imply that both instructions succeed. The expandable decomposition shows the audio-only preference b and the instruction lifts ρ+ and ρ−.

All values are nats per caption token, not confidence percentages or generated answers. Decisions use full precision; labels show six significant digits. Very small nonzero margins retain their sign but need not be robust effects. Magnitude comparisons across differently tokenized models are not calibrated.

The default averages all four prompt frames before deciding crossover. The instruction text on each card uses the first frame as representative wording.
